**Status: READY — needs founder click.** PR drafted, **not opened**.

## Submission URL
https://github.com/punkpeye/awesome-mcp-servers (fork → branch → PR)

## Account needed
GitHub account (the founder's) — to fork and open the PR.

## Founder clicks (step by step)
1. **Fork** https://github.com/punkpeye/awesome-mcp-servers
   (top-right "Fork" button).
2. In the fork, create a branch: `add-sincor-marketplace-mcp`.
3. Edit `README.md`: find the section `### 🤝 Agreements & Coordination`
   and insert the one-line entry from `pr-diff.md` (this folder) in
   **alphabetical order** among the existing entries.
4. Commit with message `Add SINCOR Marketplace MCP`; push the branch to the
   fork.
5. Open a pull request against `punkpeye/awesome-mcp-servers` `main`:
   - Title: `Add SINCOR Marketplace MCP`
     (optional: append `🤖🤖🤖` per their CONTRIBUTING for agent-PR fast-track)
   - Body: paste the proposed body from `pr-diff.md`.
6. Respond to any maintainer review comments (usually format nits).

## Review process
Maintainer review; they may ask for re-categorization or rewording. The
draft already follows their rules: linked name, one line, alphabetical,
accurate description.
