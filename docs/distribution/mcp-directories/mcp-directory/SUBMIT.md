# mcp.directory — submission steps

**Status: READY — needs founder click.** Nothing submitted; no account created.

## Submission URL
https://mcp.directory/submit

## Account needed
None. No sign-in, no fee (verified 2026-10-12 by inspecting the page:
no login control anywhere on it).

## Founder clicks (step by step)
1. Open https://mcp.directory/submit
2. **GitHub Repository URL** → paste
   `https://github.com/OrderofChaos33/SINCOR2`
3. npm package / PyPI package → **leave blank** (we ship neither)
4. **Short description** → paste the 97-char short description from
   `listing.md` (this folder)
5. **Your email** → founder's email (optional; gets the review notification)
6. Click **Submit for Review**

## Review process
Per the page: they pull metadata from GitHub, auto-detect tools, generate
install configs, review for quality/accuracy **within 24 hours**, then publish.
After 24 h, search https://mcp.directory for `SINCOR`, or try the listing URL
pattern `https://mcp.directory/servers/orderofchaos33/sincor2`.

## If it is already listed
mcp.directory auto-discovers from the Official MCP Registry. If the server
appears on its own after the registry publish, **claim** it instead of
re-submitting (their "Already listed?" section explains the claim flow).
