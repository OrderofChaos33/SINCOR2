https://mcp.so/submit

## Account needed
None. The form has no sign-in (verified 2026-10-12). Optional paid tier:
$39 one-time for immediate publish + verified badge + featured placement —
**not recommended unless the founder decides it's worth it; the free queue is fine.**

## Founder clicks (step by step)
1. Open https://mcp.so/submit
2. **Repository URL\*** → paste `https://github.com/OrderofChaos33/SINCOR2`
3. **Name** → paste `SINCOR Marketplace MCP`
4. Type/category → select `MCP Server` (and the closest category offered,
   suggested `Developer Tools` / `AI Agents` / `Finance`)
5. **Description** → paste the long description from `listing.md`
   (in this folder)
6. **Server config** → paste the `mcpServers` JSON from `listing.md`
   (if the form asks for one)
7. **Skip the paid tier** (or check it only if you want the $39 fast-track)
8. Submit → listing enters the review queue

## Review process
Per the submit page, free submissions go through a review queue before going
live. No ETA is published on the page. After ~1 week, check
https://mcp.so and search "SINCOR".

## If the listing looks wrong after it goes live
mcp.so scrapes the repo for metadata; the canonical fix is correcting
`README.md` / the repo, then asking for a re-scrape (their contact link is on
the site). Do not paste unproven claims in the description to "improve" it —
the claim register in the parent README is the ceiling of what we may say.
