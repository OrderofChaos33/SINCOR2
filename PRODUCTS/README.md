# PRODUCTS collateral

This directory expands each product-line-02 SKU into working collateral that mirrors the canonical data in `/products`.

Each SKU folder contains:

- `SPEC.md` — exact product definition, scope, exclusions, readiness, and implementation mapping
- `MEDIA.md` — positioning, proof points, approved language, and message constraints
- `COMPLIANCE.md` — claims guardrails, evidence requirements, and prohibited statements
- `SALES.md` — pricing, qualification, objection handling, packaging, and close guidance

When `/products` changes, update these files to match the canonical JSON first.
